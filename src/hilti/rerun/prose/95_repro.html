10  reproducing it

The whole campaign, as commands

Every path resolves through config/paths.yaml, so nothing below is machine-specific. config/hilti/sequences.yaml names the run each sequence's numbers come from; it now says default_run: rerun_r1.0 for all fifteen, which is the first time one run has covered the whole dataset. 

# 1  FAST-LIO over all 15, two batches because the rigs need different configs
python3 src/batch_fastlio.py --dataset hilti_2023 --glob '*_fastlio_bag' \
    --config-file hilti/fast_lio_hilti.yaml       --run-name rerun_r1.0 -r 1.0 --no-rviz \
    --only $HANDHELD
python3 src/batch_fastlio.py --dataset hilti_2023 --glob '*_fastlio_bag' \
    --config-file hilti/fast_lio_hilti_robot.yaml --run-name rerun_r1.0 -r 1.0 --no-rviz \
    --only $ROBOT

# 2  score, then measure each map frame's gravity tilt
for s in $SEQS; do
  python3 src/hilti/eval_fastlio.py "$s" --run rerun_r1.0 --json auto --tag rerun
  python3 src/hilti/align_map.py    "$s" --run rerun_r1.0
done

# 3  levelled LAS + .kdm, in the mapping container (it has PDAL)
RUN=rerun_r1.0 SERVICE=mapping scripts/hilti/in_container.sh \
    /opt/sdp/scripts/hilti/build_maps.sh

# 4  own-map localization
for s in $SEQS; do
  python3 src/hilti/gen_cfg.py "$s"
  scripts/hilti/in_container.sh /opt/sdp/scripts/hilti/run_seq.sh "$s" 1
  python3 src/hilti/eval_localizer.py "$s" --run rerun_r1.0 --json auto
done

# 5  pick a hub per site from the measured coverage, not from map size
python3 src/hilti/xseq.py coverage --run rerun_r1.0
for site in 1 2 3; do
  python3 src/hilti/xseq.py matrix --site $site --run rerun_r1.0 --half-extent 70 --yaw-step 2
done
python3 src/hilti/xseq.py hubs

# 6  cross-sequence: register, then replay against the hub's map
python3 src/hilti/xseq.py register "$HUB" "$SEQ" --run rerun_r1.0 --half-extent 70
python3 src/hilti/gen_cfg.py "$SEQ" --map-seq "$HUB"
NAME=${SEQ}_in_${HUB} scripts/hilti/in_container.sh \
    /opt/sdp/scripts/hilti/run_seq.sh "$SEQ" 1
python3 src/hilti/eval_localizer.py "$SEQ" --run rerun_r1.0 \
    --csv  "$RES/run_${SEQ}_in_${HUB}.csv" \
    --align "$RES/xreg_${SEQ}_in_${HUB}.json" \
    --json  "$RES/kd_${SEQ}_in_${HUB}.json"

# 7  the report: collect -> figures -> tables -> assemble
python3 src/hilti/rerun/collect.py && python3 src/hilti/rerun/figures.py
python3 src/hilti/rerun/tables.py  && python3 src/hilti/rerun/assemble.py

Two of those steps changed shape for this campaign. src/hilti/xseq.py is new: it does for Hilti what register_maps.py did for ConSLAM, but with the gravity stage replaced by the rotation align_map.py already measured, which is a better estimate than normals off the cloud because it comes from the filter that built the map. gen_cfg.py grew a --map-seq mode, and run_seq.sh a NAME so a cross-sequence run cannot overwrite the own-map artefacts of the same bag.
